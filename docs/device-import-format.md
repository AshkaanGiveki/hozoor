# فرمت ورود تردد

CSV canonical شامل `employeeCode,timestamp,type` است؛ `type` می‌تواند `IN`, `OUT`, `ورود`, `خروج` باشد. XLSX از اولین worksheet خوانده می‌شود. شناسه، زمان و نوع در wizard قابل نگاشت هستند. رکورد نامعتبر ذخیره نمی‌شود و fingerprint دستگاه/شناسه/زمان/نوع از duplicate جلوگیری می‌کند.
